Production Operational Notes

  • Dual Gateways: Both Stripe and Razorpay are wired to create real checkout sessions / orders. When keys are unconfigured in development, the system runs the Mock Provider. Set real credentials in Super Admin → Settings → Payments for live production charges.
  • Sealed Secrets: All sensitive gateway keys (Stripe, Razorpay, SMTP, Twilio) are encrypted at rest in MongoDB using AES-256-GCM / Fernet crypto.
  • Safe Outbox: Transactional emails buffer safely in MongoDB if SMTP credentials are unset, ensuring notifications are never dropped.
